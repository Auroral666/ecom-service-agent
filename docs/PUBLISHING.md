# Git 管理与上传范围

本地 Git 管理源码、可重建的配置示例、固定模拟业务数据和正式文档。固定模拟数据允许上传至云端仓库，业务日期统一设置在 2026 年 5—8 月；真实用户运行数据不纳入 Git。

| 内容 | 拟纳入 Git | 原因 |
| --- | --- | --- |
| `app/` 的应用源码、`main.py`、`mcp_server/` | 是 | Agent、API、账号、人工服务和工具实现 |
| `app/tools/mock_data.py`、固定测试样例 | 是 | 可公开的模拟订单、商品和物流数据，日期为 2026 年 5—8 月 |
| `app/knowledge/`、`app/skills/`、固定评估样例 | 是 | 业务知识、可复用流程与固定评估输入 |
| `frontend/src/`、配置、`package.json` 与 lockfile | 是 | 可复现的前端源码与依赖版本 |
| `scripts/`、启停 CMD | 是 | 本机多服务管理 |
| `tests/`、依赖清单 | 是 | 代码验证和安装说明 |
| 双语 README、正式模块文档、维护者提供的运行截图 | 是 | 项目展示与维护 |
| `.env.example` | 是 | 脱敏配置示例 |
| `.env` 及其私有变体 | 否 | 聊天和嵌入服务凭据 |
| `app/sessions/` 全部内容 | 否 | 账号、邀请信息、登录凭据摘要、聊天、记忆与向量索引 |
| `.runtime/`、`.local-backups/`、`temp/` | 否 | 日志、进程信息、备份与验收产物 |
| `frontend/.ui-review/` | 否 | 浏览器测试账号、历史截图、日志和辅助脚本 |
| `.venv/`、`node_modules/`、`dist/`、模型权重 | 否 | 本机依赖与可再生成产物 |

## 模拟数据

模拟数据范围、订单号和日期分布见 [模拟数据说明](MOCK_DATA.md)。订单号内的日期与下单日期一致，物流轨迹与对应订单关联。订单状态为固定场景快照，不随真实时间推进。

## 验证方式

只运行 README 中明确列出的五组隔离 Web 回归，再执行前端 `npm run build`。旧 `test_*.py` 中部分为真实模型演示，不使用无差别批量执行来证明“无网络测试”。

在 Windows 的共享临时目录发生权限问题时，可为 pytest 指定新的项目内路径，例如 `--basetemp=temp/pytest-一次性唯一名称`。每次使用新目录，避免让 pytest 管理已有文件。

2026-11-03 本机发布准备验证：五组隔离回归合计 30 项测试通过；Vue TypeScript 检查与 Vite 生产构建通过。构建仍提示主 JavaScript 包较大，尚未为此进行代码分割优化。初次 pytest 因系统共享临时目录权限失败，改用新的项目内临时目录后通过，未修改测试断言。
